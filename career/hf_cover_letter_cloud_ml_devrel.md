# Cover Letter - Hugging Face Cloud ML DevRel

Dear Hiring Team,

I am applying for the Cloud ML DevRel Engineer role because I enjoy building practical ML systems and explaining them well. The role you described is a close match for the way I like to work: ship something useful, document it clearly, and make it easy for the community to adopt, test, and discuss.

My current project, `nsys-llm-explainer`, is a good example of that style. I turned Nsight Systems SQLite traces into a readable performance analysis workflow with a CLI, dashboard, reproducible synthetic fixtures, screenshots, and explicit capture guidance. The project is built to be demoed, taught, and reused. It can show a user exactly where GPU time is going, how NCCL and NVLink interact, where CPU-GPU synchronization is slowing inference, and how current traces compare to baselines.

That matters for DevRel because the best technical content has to do three things at once: demonstrate real value, lower adoption friction, and give people a path to try the workflow themselves. I can write the code, the docs, the demo narrative, and the benchmark story. I can also keep the content honest by making limitations visible and by explaining what the tool can and cannot infer from the underlying trace data.

What I would bring to Hugging Face:

- A strong open-source mindset with a bias toward reusable examples and public artifacts.
- The ability to turn infrastructure-heavy ML content into approachable demos and tutorials.
- Comfort with partner-style conversations about performance, deployment, and developer workflow.
- The habit of producing assets that work across README, blog post, webinar, live demo, and conference talk formats.

If I joined the team, I would aim to ship content that shows how to run Hugging Face models efficiently on cloud platforms and accelerators, while also making the path to adoption clear enough for a broad technical audience. I would also be happy to present the project as a live Hugging Face Space titled `nsys-llm-explainer — Instant Nsight Trace Analyzer for Cloud LLM Inference` so the demo can be shared publicly and discussed interactively.
